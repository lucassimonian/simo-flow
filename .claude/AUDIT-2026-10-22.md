# Audit: make the repo read as Apple-standard to a senior engineer

**Frame** (Lucas, 2026-10-22): the reader is a senior engineer opening this repo
cold. The goal is that they come away thinking it was built properly, not vibe
coded — details not missed, nothing rushed, files organised, code pristine.
**Stars are not the measure.** Evenness is.

## What a reviewer already sees and rates highly

- Comments explain *why*, with dates and the incident that caused the rule
  ("v2.2.1 did that and froze the machine")
- A mutation sweep: 64 guards, each broken on purpose, CI-gated
- Zero TODO / FIXME / HACK anywhere
- Conventional commits, PRs rather than pushes to main, changelog, 5 releases
- CONSTRAINTS.md naming the bar with the command that proves each line

## What makes them wince — measured 2026-10-22

| Finding | Count | Breaks |
|---|---|---|
| Functions over 50 lines | 4 (`paste_text` 97, `_tee_logs` 60, `_prepare_device` 54, `end` 51) | standard.md "<50 lines" |
| Broad `except` clauses | 8 | standard.md "no silent failures" |
| Public functions with no return type | 23 of 78 | — |
| Public functions with no docstring | 41 of 78 | — |
| Test files touching real hardware | 0 of 7 | lessons 019 |

**The diagnosis is evenness, not quality.** Parts of this repo are better than
professional work; other parts were not finished to the same bar, and a reviewer
sees the seam.

## The work, in order of what a reader notices

1. **Split `paste_text` (97 lines)** — the most important function in the app,
   twice the repo's own limit. Highest-visibility fix.
2. **Audit the 8 broad excepts** — each either gets a comment saying why it is
   safe, or gets narrowed. A reviewer cannot tell which are justified today.
3. **Finish the type hints, then gate on them** so they cannot drift again.
4. **One real-hardware test** — the gap both live bugs occupy.

## Bounds for unattended work

- Every change: `check.sh --fast` green, new guards killed by the sweep.
- Each item its own commit, so any can be reverted alone.
- **No push.** simo-flow is public; Lucas approves that himself.
- **The soak harness is built but not run** — it takes the microphone, and he
  is using the machine.
